# Registri

Interaktivna učilnica računalniške arhitekture v slovenščini. Vključuje osem učnih sklopov, zaključni kviz in laboratorij za pisanje kratkih programov v zbirnem jeziku x86 (NASM, 32-bitni Linux).

Stran odpreš tudi lokalno. Prenesi repozitorij kot ZIP, razširi arhiv in v brskalniku odpri `index.html`. Rešitve in napredek se shranjujejo v brskalniku.
